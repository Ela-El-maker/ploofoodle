Get Started

Install the app, complete onboarding, and start using your account in minutes.

Install from store

  1. Tap your platform store button.
  2. Install and open the app.
  3. Allow requested permissions when prompted.
Google Play App Store

Manual APK install (Android)

  1. Download the latest APK from the official link.
  2. Open Android settings and allow installs from trusted sources.
  3. Install the APK and keep Play Protect enabled.
  4. Optional: verify the published SHA256 checksum before install.
